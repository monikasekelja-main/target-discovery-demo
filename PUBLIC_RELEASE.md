# Public copy and provenance

This is a standalone synthetic target-discovery demonstration, with neutral project wording and generic role labels. It is not a company programme, clinical result or independently validated target-discovery system.

## What changed for this copy

- Removed company-specific and recruitment framing, personal reviewer names and local home-directory paths from source and documentation.
- Renamed optional environment settings to `TARGET_DEMO_WORKSPACE` and `TARGET_REVIEW_MODEL`.
- Replaced private execution histories with freshly constructed synthetic cases. Reviews are `simulated_human`; follow-up notes are scripted scope clarifications, not claims of additional experiments. Request and response delivery remains `local_simulation`.
- Replaced private live-model reports with `scripted_offline_test` reports from the existing offline provider. These demonstrate interfaces, not AI quality. No historical model output or original operator approval is represented as a new validated record.
- Updated authored fixture bindings to the neutral policy wording, then created new state and exports through the normal workflow APIs. The policy status sentence changed; numerical criteria, donor data and calculation code did not.
- Added a visible public-replay disclosure and a replay/rebuild guide. Fixed the ignore rule so nested saved exports are included by Git.
- Excluded original databases, private report captures, visual-QA captures, slides, conversations, repository history, credentials, caches and environments. Public scientific citations retain their authors and links.

The source checkout and original private bundle were left intact. This copy has no Git history and has not been published. `SOURCE_MANIFEST.json` records the packaged file hashes, excluding itself.

## Boundaries

Published disease background, fictional target evidence, frozen predictions and untested hypotheses remain distinct. Programme context is display-only and is not injected into existing agents. Shared-donor methods do not establish independent replication. Expression reduction does not establish antibody blockade equivalence. Culture cell-preservation checks do not establish systemic safety.

A public repository makes the material readable; no open-source reuse licence is supplied in this package.

Verification for this release is recorded in `PUBLIC_VERIFICATION.md`. Older development notes describe earlier local checks; they are not evidence that live model behaviour was evaluated in this public copy.
